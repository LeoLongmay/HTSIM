# Spec: PRISM congestion-decomposition figure (C_cc(t) + C_spray(t))

**Date:** 2026-06-20
**Status:** design approved (user), spec under review
**Branch:** prism-motivation-redesign (local only; origin = spcl/HTSIM public upstream — never push)

## 1. Goal

Add a mechanism figure that plots PRISM's two decomposed signals — the floor `C_cc` and the spread
`C_spray` — **as time series**, side by side for the symmetric (failed=0) and asymmetric (win)
regimes, at both 128-node and 1024-node scale. This is the most direct visualization of PRISM's
"congestion decomposition" and of the "two faces" result already documented in
`../expA_f0_diagnosis/`: at the asymmetric win point `C_spray` is persistently large (a real
reroutable structure) while `C_cc` hugs the target; at the symmetric point `C_spray` is a decaying
startup transient.

**Pure plotting feature: no controller change, no new simulations.** The data already exists in the
committed PRISM per-epoch logs.

## 2. Output figures (two 1×2 panels = the requested 2×2)

- `expA_delaydriven/figs/figA2dd_decomp.{pdf,png}` — **left**: 128, failed=0 (symmetric); **right**:
  128, failed=8 (asymmetric win). Named into the existing `figA2dd_*` mechanism family.
- `expD_scale1024/figs/figD1_mech_decomp.{pdf,png}` — **left**: 1024, failed=0 (symmetric);
  **right**: 1024, failed=32 (asymmetric win). Named into the existing `figD1_mech_*` family.

(Kept as two per-folder figures rather than one cross-folder 2×2, so each renderer reads only its own
folder's `data/`. In the paper they stack to form the 2×2.)

## 3. Per-panel content

- **x-axis:** time (ms). **y-axis:** queuing delay (µs); `C_cc` and `C_spray` share the axis (both µs).
- **`C_cc(t)`** (floor → fed to CC): a faint raw per-epoch line + a bold ~20 µs time-binned overlay.
  Hugs the target.
- **`C_spray(t)`** (spread = max−min → fed to spraying): faint raw + bold binned overlay. Persistently
  large on the asymmetric (right) panels; decaying on the symmetric (left) panels.
- **target reference line:** a dashed horizontal line at ≈1 RTT (the `base_rtt_ns` from the epoch log,
  ≈14 µs) — the `T_cc`/`T_spray` threshold `decide_region` compares against. Labeled.
- **per-panel annotation:** `C_spray` first-half → second-half mean (µs), computed from the same epoch
  rows split at the midpoint of the steady window — quantifies persistence (symmetric: drops;
  asymmetric: roughly flat). One short text line per panel.
- Colors/styles from `common/plot_style.py`; `C_cc` and `C_spray` clearly distinct; readability is a
  first-class goal (this figure must NOT look like the tangled cwnd panel).

## 4. Data source (zero new simulations)

Reuse the committed per-failed-sweep PRISM epoch CSVs (schema
`time_ns,flow_id,base_rtt_ns,c_cc_ns,c_spray_ns,region,cwnd_bytes,samples,cut`, parsed by
`metrics.parse_prism_epoch`), **seed 13, all 2 MB** (so each left/right pair is apples-to-apples on
message size and seed):

| panel | epoch CSV |
|---|---|
| 128 symmetric | `expA_delaydriven/data/expA_prism_f0_s13.epoch.csv` |
| 128 asymmetric | `expA_delaydriven/data/expA_prism_f8_s13.epoch.csv` |
| 1024 symmetric | `expD_scale1024/data/expD1_prism_f0_s13.epoch.csv` |
| 1024 asymmetric | `expD_scale1024/data/expD1_prism_f32_s13.epoch.csv` |

All four verified present. If a run were re-done, these are regenerated by the existing `repro.sh`
(every PRISM sweep run already sets `PRISM_EPOCH`); this feature adds no new run.

## 4.1 Aggregation note (honest)

The figure is a **single-seed (seed 13) time-series slice**, exactly as the existing mechanism panels
(`figA2dd_signal`, `figD1_mech_signal`) are. A time series is not seed-averaged; the per-panel
persistence annotation is the quantitative summary, and the 5-seed means already live in the perf
figures and `../expA_f0_diagnosis/`.

## 5. Invariants (non-negotiable)

- **No controller change.** `uec.{h,cpp}`, `prism_decompose.h`, the mains — untouched. PRISM stays O(1).
- **No new simulations / no new raw data.** Reuses committed epoch CSVs only.
- **No change to any existing figure.** Only two new figures are produced; the shared renderer is a
  NEW function — existing `render_*` calls are untouched.
- **Reproducibility carried over:** rendered from gitignored `data/` via `make_figs.py`; figures
  committed with `git add -f`; `make_figs.py --selftest` still passes.
- **Communication in Chinese; no git commit unless the user explicitly asks (per-task local commits
  ARE authorized for the subagent-driven run); never push.**

## 6. Change set

| File | Change |
|---|---|
| `common/perf_figs.py` | Add `render_decomposition(data_dir, figs_dir, tag_prefix, cells, fig_stem, ...)` — reads each cell's epoch CSV via `metrics.parse_prism_epoch`, plots `C_cc(t)`+`C_spray(t)`+target+annotation into a 1×N panel figure, saves via `plot_style.save`. `cells` = list of `(failed, panel_label)`. |
| `expA_delaydriven/make_figs.py` | One call: `render_decomposition(DATA, FIGS, "expA", [(0,"failed=0 (symmetric)"),(8,"failed=8 (asymmetric)")], "figA2dd_decomp")`. |
| `expD_scale1024/make_figs.py` | One call: `render_decomposition(DATA, FIGS, "expD1", [(0,"failed=0 (symmetric)"),(32,"failed=32 (asymmetric)")], "figD1_mech_decomp")`. |
| `expA_delaydriven/figs/*`, `expD_scale1024/figs/*` | The two new rendered figures, `git add -f`. |

The renderer uses seed 13 and the `{tag_prefix}_prism_f{failed}_s13.epoch.csv` naming (matching the
committed files). Binning reuses the existing ~20 µs time-bin approach already used for the C_cc
overlay in `render_mechanism`.

## 7. Acceptance criteria

- **(a)** All four panels render (both `.pdf` and `.png`); `make_figs.py --selftest` passes for both folders.
- **(b)** On the asymmetric (right) panels, the steady-state binned `C_spray` is visibly **larger** than
  on the symmetric (left) panels; `C_cc` hugs the target line in all four.
- **(c)** The persistence annotation shows `C_spray` first→second-half **decreasing** on the symmetric
  panels and roughly **flat** on the asymmetric panels (the "transient vs persistent" contrast).
- **(d)** Readability: at most the two signals (raw faint + binned bold) + target + one annotation per
  panel — not a tangle.
- **(e)** No diff to controller files or to any existing figure's bytes beyond the two new figures.

- Any new simulation, controller change, or change to existing perf/mechanism figures.
