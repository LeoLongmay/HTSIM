# Permutation plotting-data archive

`archive_data/figE_p128_sweep.csv` and `archive_data/figE_p1024_sweep.csv` each store 49 displayed cells: seven throttled-link values times seven algorithms, with all three plotted means, population-standard-deviation error bars, and five seeds.

Run `python3 archive_fig_data.py --render` from this directory to redraw all six panels without simulation logs.
