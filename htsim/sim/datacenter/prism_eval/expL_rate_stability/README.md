# ExpL — DecMT aggregate delivery-rate stability

ExpL measures aggregate delivery-rate convergence and steady-state variation
for OPS, REPS, STrack, and DecMT in the fixed 128-host delay-driven
many-to-many workload.  The rate is a controller-neutral sum of sink delivery
rates; it is not a direct packet-departure trace.

## Reproduction

```bash
cd htsim/sim/datacenter/prism_eval/expL_rate_stability
bash repro.sh historical-check
bash repro.sh full
```

`historical-check` runs the representative DecMT asymmetric case and asks the
analysis step to compare its raw sink trace with the recorded provenance.
`full` runs the complete formal matrix, analysis, and renderer.  Smoke output
is isolated under `data/smoke/`, so it can never alter the formal raw bundle.
The runner reuses only output bundles whose manifest and retained raw files
have matching SHA-256 hashes.

## Locked matrix

The formal matrix contains exactly 60 runs.  Every listed row uses seeds
`13, 14, 15, 16, 17` (five runs).

| Kind | Condition / setting | Arm or beta | Runs |
| --- | --- | --- | ---: |
| Primary | symmetric (`failed=0`) | OPS | 5 |
| Primary | symmetric (`failed=0`) | REPS | 5 |
| Primary | symmetric (`failed=0`) | STrack | 5 |
| Primary | symmetric (`failed=0`) | DecMT | 5 |
| Primary | asymmetric (`failed=8`) | OPS | 5 |
| Primary | asymmetric (`failed=8`) | REPS | 5 |
| Primary | asymmetric (`failed=8`) | STrack | 5 |
| Primary | asymmetric (`failed=8`) | DecMT | 5 |
| Beta sensitivity | asymmetric (`failed=8`) | `beta=1.0` | 5 |
| Beta sensitivity | asymmetric (`failed=8`) | `beta=0.5` | 5 |
| Beta sensitivity | asymmetric (`failed=8`) | `beta=0.3` | 5 |
| Beta sensitivity | asymmetric (`failed=8`) | `beta=0.15` | 5 |

Every case uses `fat_tree_128_1os.topo`, 8 paths, an 8 ms end time, 128
nodes, MTU 4150, `-disable_trim`, and the byte-exact workload generated by:

```text
many2many.py 64 16 pairs 2000000 128 16
```

DecMT uses `-prism_smooth_beta 0.3 -prism_hysteresis 0.25
-prism_engage_spread 28 -prism_disengage_spread 20`; beta cases change only
`-prism_smooth_beta`.  Sink logging is fixed at 10 microseconds.

## Outputs

Raw sink traces and manifests are written below `data/raw/`.  Each primary or
beta case has `rate_<case-id>.sink.txt` and `<case-id>.manifest.json`; the
manifest records the logical common-runner command, locked environment,
workload and executable hashes, and hashes of retained sink, stdout, and
idmap outputs.
