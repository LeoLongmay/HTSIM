PRISM per-path-RTT Incast Demo — Assessment (2026-06-07)
========================================================
Metric (faithful to the per-path definition): for each flow, per path i (= sender-chosen
path_id), q_i = rtt_i - rtt_min_i (latest raw RTT on path i minus that path's historical
min raw RTT). C_cc = min_i q_i ; C_spray = max_i q_i - min_i q_i. Measured via a read-only
env-gated hook in uec.cpp logging (time, flow, path_id, raw_rtt) per valid ACK.
Scenario: 32-sender incast -> one dest host0 in pod0; -failed degrades pod0's core->agg
ingress (the layer flows INTO pod0 traverse). Sender path pool -paths 8 (small pool so each
path is densely sampled; also the realistic regime for a sender tracking per-path state).
Steady window [500,1500]us. Primary statistic: cross-flow MEDIAN of per-flow steady means
(robust; avoids comparing a single run-dependent representative flow across configs).

CRITERIA VERDICTS (design section 6)
------------------------------------
(i)  Decisive run both components nonzero?           YES. reps_a8: C_spray 3.37us, C_cc 1.45us;
       the time series (fig1) shows both sustained and distinct.
(ii) REPS C_spray << OBLIVIOUS C_spray?              YES. 3.37 vs 8.44us (~2.5x). Better LB
       flattens the per-path spread. (fig2)
(iii) C_cc invariant to LB choice?                   YES. REPS 1.45us ~= OBLIVIOUS 1.54us
       (within ~6%). The floor is unchanged by load balancing. (fig2)
(iv) Orthogonal drivers (C_spray~asymmetry, C_cc~load)?  NO / MIXED.
       - C_spray vs -failed is NON-monotonic (7.17, 7.93, 3.37, 4.21) and is already large
         at failed=0. So C_spray here is driven mainly by incast + REPS spraying itself,
         not by link asymmetry. (fig3, fig4-left)
       - C_cc rises only weakly with incast degree (16:1.33 -> 32:1.45) and n=64 could not be
         aggregated (too few per-path samples), so load-monotonicity is inconclusive. (fig4-right)

CONCLUSION: 部分成立 (core decomposition holds; driver-attribution does not).
The central PRISM premise is supported: bottleneck congestion separates into an
LB-removable component (C_spray, which REPS lowers ~2.5x vs Oblivious) and an
LB-invariant floor (C_cc, unchanged by LB choice -> only CC can reduce it). This is the
LB/CC role separation the decomposition needs, and it is clean under the LB ablation.
What is NOT demonstrated: the cleaner causal story that C_spray is gated by link asymmetry
and C_cc by load. In incast-to-one-host, C_spray is dominated by the spray/incast dynamics
themselves (present even when symmetric), and the load sweep is sampling-limited.

依据 (evidence): reps_a8 vs obl_a8 cross-flow medians (C_spray 3.37 vs 8.44; C_cc 1.45 vs
1.54); fig1 (both nonzero, distinct dynamics); fig2 (the LB contrast).

意外 (surprises):
1. The single representative-flow view (per-tag "mean" lines in summary.txt) INVERTED the LB
   contrast (it made OBL look like LESS spray) — an artifact of each run's representative flow
   being a different sender. The cross-flow median fixes it and is the statistic to trust.
2. C_spray is high even with NO link asymmetry (reps_a0 = 7.17us): incast + REPS per-packet
   spraying alone produces large per-path RTT spread; the asymmetry knob does not cleanly
   modulate it in this scenario.
3. With the default -paths 64, C_cc collapses to ~0 (sparse per-path sampling -> some path
   always sits at its own min). The per-path-min floor is only observable when the sender
   tracks few enough paths to sample each densely (-paths 8 here). This directly bears on the
   O(N)->O(1) per-path-state question: a realistic small path set is also what makes the
   decomposition measurable.

下一步建议 (next steps):
- To test the orthogonal-driver story cleanly, use a scenario where asymmetry, not incast,
  sets the spread: e.g. the round-2 dest-pod-overload scenario (whole-pod ingress degraded),
  where the LB-invariant rate/RTT floor was already shown in throughput space; measure its
  per-path RTT there. Also fix a consistent set of measured flows across configs and ensure
  >=200 samples/flow at every incast degree (longer -end or fewer senders) so the load sweep
  is conclusive.
- The clean (i)/(ii)/(iii) result already supports PRISM's core motivation; the (iv) gap is
  about which knob drives which component, which is a refinement, not a contradiction.

SCOPE/CAVEATS: single seed per config; one topology; incast-to-one-host; the C++ change is a
read-only env-gated log (no simulation-behavior change). Final go/no-go left to the user.

ROUND 4 — Driver attribution (criterion iv), 2026-06-08
================================================================================
Goal: close the iv gap from Round 3 ("C_spray ~ asymmetry" iv-a; "C_cc ~ load" iv-b),
testing the user's intuition "symmetric -> small C_spray, asymmetric -> large".

METRIC CHANGE: added two baselines beside the original per-path own-min ("own"):
  own    : q_i = rtt_i - min_i(path i's own history)           [Round 3 default]
  global : q_i = rtt_i - B_flow (flow's min over all paths/time); C_spray = max-min raw RTT
  const  : q_i = rtt_i - B_prop (a FIXED true-propagation floor, measured uncontended)
B_prop = 13945 ns = min raw RTT of an uncontended N=1 incast run (same topology, healthy path).
In-window sample gate tightened to >=200 ACKs INSIDE the steady window per flow.

----------------------------------------------------------------------
iv-a  (C_spray ~ asymmetry):  NOT cleanly demonstrated (metric artifact fixed; spray-dominated)
----------------------------------------------------------------------
Pre-validation (existing Round-3 incast CSVs, relaxed min_samples=100; mvp_runs3/prevalidation.txt):
  own    C_spray vs -failed [0,4,8,12] = [7.33,6.49,6.21,7.51]  NON-monotonic (Round-3 reversal)
  global C_spray vs -failed             = [2.58,2.74,3.33,3.96]  monotonic UP  <- global fixes the
     own-min artifact (a degraded path's structural slowness no longer hides in its own min).
Scenario A (whole-pod overload: 32 senders -> 8 hosts in pod0; default window [500,1500]us):
  OBL  C_spray(global) vs -failed = [9.07, 8.86, 9.87, 12.44]  monotonic=NO (f4 dip; f0 large)
  REPS C_spray(global) vs -failed = [7.36, 6.36, 7.43,  7.31]  ~flat (REPS balances asymmetry away)
  Moderate-load probe (8 senders -> 8 dests, OBL) = [12.58,13.34,12.60,12.40]  flat & high.
  => C_spray is dominated by per-packet spray + NSCC dynamics (large ~9us even at SYMMETRIC f0);
     asymmetry only weakly/non-monotonically adds to it (OBL f12 is +37% vs f0). The user's
     "symmetric -> small" holds only if the symmetric case is uncongested AND the LB balances;
     under Oblivious overload neither is true. (fig5, fig6)

----------------------------------------------------------------------
LB ABLATION (core premise "LB removes C_spray"):  CLEAN / HOLDS
----------------------------------------------------------------------
REPS C_spray < OBLIVIOUS C_spray at EVERY asymmetry level (fig5):
  f= 0: OBL 9.07 vs REPS 7.36     f= 4: 8.86 vs 6.36
  f= 8: 9.87 vs 7.43              f=12: 12.44 vs 7.31
=> C_spray is genuinely LB-removable. This is the LB half of the decomposition, and it is robust.

----------------------------------------------------------------------
iv-b  (C_cc ~ load):  HOLDS WEAKLY, but ONLY against a true-propagation baseline
----------------------------------------------------------------------
Scenario B (incast N -> host0, symmetric, REPS, -end 8ms, window [1000,7000]us; fig8):
  C_cc(const, vs 13945ns) vs N[16,32,64] = [10.22, 10.35, 11.38] us  monotonic UP  <- iv-b
  C_cc(global, per-flow)                  = [ 7.61,  4.97,  1.41]     FALLS (contaminated)
  C_cc(own,    per-path)                  = [ 2.10,  1.16,  0.78]     FALLS (contaminated)
NEW FINDING (baseline contamination): under sustained congestion a flow never observes the
  empty network, so its per-flow/per-path min INFLATES with load (B_flow median 16.5->19.4->
  23.9us as N grows) and cancels the very floor we want. Only a fixed true-propagation floor
  reveals that C_cc rises with load. Caveat: the last hop is saturated at all N, so the rise
  is modest (~10->11us).
Entanglement (fig7): in Scenario A, increasing -failed THROTTLES load (NSCC backs off; the
  one healthy path empties), so C_cc(const) FALLS [OBL 6.10,4.39,3.45,0.46]. Asymmetry and
  load are not independent knobs here -> a clean orthogonal attribution is structurally hard.

VERDICT
----------------------------------------------------------------------
(iv) overall:  NOT closed.  iv-a not clean (C_spray spray-dominated, asymmetry weak/non-mono);
  iv-b holds only weakly and only with a true-propagation baseline; asymmetry & load entangled.
CORE DECOMPOSITION + LB/CC ROLE SEPARATION:  better-supported than Round 3 ---
  - C_spray is LB-removable: REPS < OBL at every asymmetry level (fig5).  CLEAN.
  - C_cc is an irreducible floor: rises with true load (fig8), invisible to LB choice; it is
    only measurable against a true-propagation baseline (per-flow baselines self-contaminate).
CONCLUSION (refines Round-3 "部分成立"): the decomposition's LB/CC role split holds and is now
  cleanly shown for C_spray (LB ablation) and for the load-driven C_cc floor (const baseline).
  The cleaner CAUSAL story (C_spray gated solely by asymmetry, C_cc solely by load) does NOT
  hold: C_spray is spray/CC-dominated and the two drivers are entangled. Per constraints, the
  result is NOT "分解成立 + 驱动可归因", so this does NOT recommend entering a PRISM
  implementation phase. No claim is made about PRISM mechanism performance. Final go/no-go: user.

依据: fig5 (LB ablation, REPS<OBL everywhere); fig6 (own vs global baseline); fig7 (C_cc vs
  asymmetry, entanglement); fig8 (C_cc vs load, 3 baselines); prevalidation.txt (own reversal ->
  global monotonic on incast). B_prop=13945ns from N=1 uncontended run.
SCOPE/CAVEATS (Round 4): single seed; one topology; saturated bottleneck in Scenario B (load
  rise modest); whole-pod overload makes Scenario A congestion-spread-dominated; the C++ hook
  remains a read-only env-gated log (no behavior change); no new C++ this round.
